# Kernel Event

Kernel Event is an Android mobile application for managing event lotteries. It allows different types of users such as entrants, organizers, and admins to interact with events through features like event browsing, waitlists, invitations, notifications, and event history.

## Project Overview

This project was developed for CMPUT 301 as a team-based software engineering project. The application is built in Java using Android Studio and is designed around object-oriented principles, incremental development, and GitHub-based collaboration.

## Main Features

- User roles: Entrant, Organizer, Admin
- Event creation and management
- Event browsing and overview
- Waitlist and lottery functionality
- Invitation and notification system
- User profiles
- Event history tracking

## Tech Stack

- **Language:** Java
- **Platform:** Android
- **IDE:** Android Studio
- **Backend / Data:** Firebase / Firestore
- **Version Control:** GitHub
